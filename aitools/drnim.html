Hinweis: Wenn du eine Aktion wählst, merkt sich die KI die Aktion für diesen Zustand. So lernt sie Schritt für Schritt, was gute Züge sind.

Lern-Matrix
Jede Zeile = Zustand (Anzahl Hölzer). In jeder Zelle: oben Q-Wert, unten: P = Spieler, A = KI.
- Grünere Zellen = höhere Q-Werte (KI findet Aktion gut).
- Blaue Einfassung markiert die aktuell von der KI bevorzugte Aktion pro Zustand.
- P = Anzahl Spielzüge, A = Anzahl KI-Züge.
